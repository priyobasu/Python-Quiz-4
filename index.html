📌 Quick Python Rules to Remember:

  • • Variable Names: Cannot start with numbers or contain spaces/hyphens!
  • • Variables in print(): Do NOT put variable names inside quotes (e.g. print(score), not print("score")).
  • • List Indexing: First element is index [0]! Accessing index out of range causes an IndexError.
  • • Comparisons: Use == to check equality in if statements, not =.
  • • Dictionaries: Look up values using keys (e.g. dict["key"]). Missing keys raise a KeyError.
