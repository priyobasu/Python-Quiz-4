📌 Key HTML Syntax Reminders:

  • Body Color Attribute: The classic HTML attribute is bgcolor (short for background color), not backgroundcolor.
  • Font/Text Color: In CSS styling, the property is simply color: ..., not font-color.
  • Lists Hierarchy: The container tag (<ul> or <ol>) wraps around list item elements (<li>).
  • Website Name: The text shown on the browser tab is placed inside <title>...</title> in the <head>.
  • Hyperlinks: Always use the concise <a href="..."> anchor tag, not <anchor>.
  • Aspect Ratio: Set width: 300px; height: auto; so images scale proportionally without looking stretched or squished.
  • Border Shorthand: Standard CSS order is size style color (e.g., border: 2px solid red;).
